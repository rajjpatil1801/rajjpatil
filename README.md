# Raj Jitendra Patil — AI & Data Science Portfolio

A next-generation, high-performance developer portfolio website built with **React 19**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Pro Tier Features

1. **🌟 Dynamic Welcome Cover Portal (`CoverPage.jsx`)**:
   - High-impact splash entrance with rotating role typewriter effect (`< NLP Developer />`, `< Club Head DATAVERSE />`).
   - Glowing multi-color animated portrait frame and live system status indicator.
   - Enter via mouse click or keyboard (**`ENTER` / `SPACE`**).

2. **🤖 "Ask Raj AI" — Floating Virtual Copilot (`AskRajAi.jsx`)**:
   - Always-accessible AI chat assistant widget in the bottom-right corner.
   - Trained on Raj's extracted resume, skills, CGPA (8.48), DATAVERSE leadership, and projects.
   - Includes quick prompt chips and realistic typing responses.

3. **🎙️ 30-Second Elevator Pitch with Waveform Visualizer (`AudioPitch.jsx`)**:
   - Embedded audio voice note player with dancing equalizer waveform bars and a toggleable verbatim transcript.

4. **⚡ Algorithmic Benchmark: Keyword Search vs Semantic Search (`SearchBenchmark.jsx`)**:
   - Interactive side-by-side comparison proving why traditional BM25/SQL LIKE matching fails on conceptual queries while Raj's vector embeddings achieve 90%+ cosine similarity matches.

5. **🟩 Engineering & DSA Activity Heatmap (`ActivityHeatmap.jsx`)**:
   - GitHub & CodeChef consistency matrix showcasing daily commits, 480+ annual contributions, and 42-day active streak.
   - Direct integration with CodeChef profile [`vincenzo_18`](https://www.codechef.com/users/vincenzo_18).

6. **🕸️ Interactive Neural Network Synapse Mesh (`NeuralBackground.jsx`)**:
   - 60fps HTML5 Canvas background with dynamic particles connecting into neural synapses that react subtly to mouse cursor movement.

7. **🧪 Live AI Lab & NLP Playground (`AiPlayground.jsx`)**:
   - Live **Sentiment Analyser Sandbox** (NLTK + VADER polarity scoring & gauge meters).
   - Live **Semantic Search & Hybrid Ranker** with adjustable TF-IDF vs Vector weight sliders.

8. **🗺️ System Architecture Pipeline (`ArchitectureFlow.jsx`)**:
   - 5-stage interactive pipeline with Python 3.11 code snippets and mathematical formulas.

9. **⚡ Command Palette (`CommandPalette.jsx`) & Terminal (`TerminalModal.jsx`)**:
   - Global **`Ctrl + K`** shortcut and interactive developer CLI (`raj@rcpit:~$`).

10. **🌓 Dark & Light Theme**:
    - One-click theme toggle with persistent storage.
